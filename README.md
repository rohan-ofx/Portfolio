# Personal Portfolio Website

A full-stack personal portfolio website to showcase my skills, projects, education and achievements.

## Live Demo
https://portfolio-orcin-seven-26.vercel.app

## Features
- Responsive personal portfolio
- Dynamic projects and skills
- Education and certifications
- Experience and achievements
- Admin dashboard
- Contact form
- Dynamic content management

## Tech Stack
- React.js
- JavaScript
- Node.js
- Express.js
- MongoDB
- Cloudinary

## Project Structure
- frontend/ – Frontend application
- backend/ – Backend API

## Installation
Clone the repository:
```bash
git clone https://github.com/rohan-ofx/Portfolio.git
```

Install dependencies separately inside frontend and backend folders. Configure the required environment variables before running the applications.
